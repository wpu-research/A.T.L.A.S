# IEEE Access version

`TranscriptionSync_IEEE_Access.docx` / `.pdf` is the manuscript laid out in the official
IEEE Access Word template. `build_ieee.py` generates it from `../TranscriptionSync_revised.docx`
and `abstract_ieee.txt` (abstract without abbreviations, ≤ 250 words).

The template itself is not redistributed: download `Access-Template-2024.docx` from the
IEEE Access author resources, place it in this folder and run `python build_ieee.py`.

Items highlighted in yellow (funding statement, author biography details and photo) are
to be completed by the author before submission.
